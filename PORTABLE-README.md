# Waveform Lab

Откройте **index.html** двойным щелчком. Сайт работает без интернета,
Telegram, сервера и установки дополнительных программ.

В списке и галерее оставлены только выбранные компактные заготовки:
**Бриллиант, Бабочка, Бантик, Стрела, Рыба, Песочные часы**.
Рыба направлена вправо, песочные часы повёрнуты на 90°.
Нажмите на карточку, чтобы открыть рисунок в редакторе.

Редактор увеличен по высоте для удобства рисования. Бирюзовый предпросмотр
показывает реальные пропорции стандартных полосок Telegram. Галерея
показывает одинаковые компактные данные при ширине сообщения 120, 180 и 240 dp.

Можно рисовать мышью, отменять изменения, сохранять и открывать JSON,
экспортировать SVG. Все файлы этой папки должны оставаться рядом.

Эти же шесть заготовок перенесены в GhostGram. Исходники генератора и
проверки находятся в проекте **Tools/waveform-lab**.
